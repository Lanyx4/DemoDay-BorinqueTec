# BorinqueTec · Demo Day (sitio web)

Página de presentación basada en `Presentacion_BorinqueTec_-_Demo_Day.pptx`.

## Estructura
```
borinquetec-demoday/
├── index.html        Contenido y estructura (secciones comentadas)
├── styles.css        Estilos, con índice numerado al inicio
├── main.js           Menú móvil, enlace activo y gráfica por año
└── img/              Logo y fotografías optimizadas
```

## Cómo usarla
Abre `index.html` en el navegador. No necesita instalación ni servidor.
Las tipografías se cargan desde Google Fonts (requiere internet).

## Personalizar
- **Colores y fuentes:** variables al inicio de `styles.css` (sección 1).
- **Cifras financieras:** objeto `DATA` en `main.js` (sección 3).
- **Textos:** directamente en `index.html`, cada sección tiene su comentario.

## Paleta
| Uso | Color |

Tipografía: **Outfit** (títulos) y **Nunito Sans** (texto).
